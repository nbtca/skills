# Vocabulary

One action, one word, on every page. A reader who sees two words assumes two actions.

## Actions

| Action | Write | Not |
| --- | --- | --- |
| Click or tap something on screen | 点击 | 点按, 单击, 点一下, 点开 |
| Press a physical key or button | 按下 | 点按, 敲, 摁 |
| Press and keep holding | 按住, with the duration | 长按 |
| Pick from a list or menu | 选择 | 选取, 选中 |
| Tick a checkbox | 勾选 | 打勾, 选上 |
| Type text | 输入 | 键入, 打 |
| Fill in a form | 填写 | 填 |
| Copy | 复制 | 拷贝 |

Name a button, menu or setting exactly as the screen shows it, inside `“”`, without the widget type: 点击“提交”, not 点击提交按钮. Keys are written as on the keycap: 按下 F2.

Quoted material is exempt: a screenshot's alt text, a transcription, or a UI label keeps its own wording.

## Address

- 你, never 您.
- No 我们 in `tutorial/manual/`, `process/` or `repair/`. Use 你 or a plain imperative. 我们 is fine in tutorials and in `about/` where it means the association.
- 请 goes on the main clause after a condition or a purpose: 如果提示输入密码，请输入开机密码. A plain step has none: 点击“下一步”.

## Words that need replacing

| Found | Replace with |
| --- | --- |
| 视情况, 如有需要, 必要时, 根据需要, 酌情 | The condition itself. If the page does not say what it is, ask the author. |
| 非常, 十分, 极大, 大大, 显著, 很好地 | The number, or nothing. If there is no number, ask the author or cut the claim. |
| 小心, 谨慎, 注意安全, with nothing after it | What to do or avoid, and what happens otherwise. If the page does not say, ask the author. |
| 最新版, 新功能, 目前, 最近 | The version number or the date. |
| 允许你, 使得, 帮助你, 让你可以 | A sentence with the reader as subject: 你可以用它…, or just the action. |
| 简单, 轻松, 只需 | Nothing. The reader decides what is easy. |
| 死机, 崩了, 挂了 in instructions | What the reader sees: 没有响应, 自动重启, 黑屏. |

## Lines to cut

These tell the reader nothing. Propose deleting them.

- Greetings and sign-offs: 感谢阅读, 祝使用愉快, 欢迎联系我们 with no contact after it.
- A closing 总结 that restates the page.
- A sentence that announces the next one: 下面介绍…, 接下来我们来看….
- A list of a tool's advantages on a page for people already using it.

## Generated prose

Do not hunt for a list of words; lists go stale. Ask of each sentence: if it were deleted, what would the reader no longer know? Sentences that fail are usually one of these:

- A judgment standing in for a fact: 是一款强大的工具, 具有重要意义.
- A closing clause that comments on the sentence before it: …，确保了系统的稳定性.
- Three items where the page only has evidence for one or two.
- A bullet list in which every item opens with a bold label and a colon, where a sentence would do.
